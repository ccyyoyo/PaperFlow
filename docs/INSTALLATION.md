# Installation (WIP)

## Prerequisites
- Rust (stable) + Cargo
- Node.js (LTS recommended)

## Setup
1. Clone the repo.
2. Install dependencies: `npm install`
3. Verify Rust toolchain: `cargo check`

## Run (dev)
- Start dev mode: `npm run tauri dev`

## Build (release)
- Build the app bundle: `npm run tauri build`
